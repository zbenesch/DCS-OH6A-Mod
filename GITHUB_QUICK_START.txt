================================================================================
TROUBLESHOOTING:
================================================================================

"fatal: not a git repository"
  → You're in the wrong folder. Use: cd "C:\Users\YOUR-USERNAME\Saved Games\DCS\Mods\aircraft\OH-6A"

"Authentication failed"
  → Check that personal access token is correct (not your password)
  → For SSH, verify key is registered on GitHub

"remote origin already exists"
  → git remote remove origin
  → Then run the git remote add command again

Files too large (>100MB)?
  → Use Git LFS: git lfs install && git lfs track "*.dll"
  → Or remove unnecessary files
